# SS-OCT-SW

Swept Source Optical Coherence Tomography Software

## Setup

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code)

### Claude Code Remote Control Setup

1. Install Claude Code CLI:

```bash
npm install -g @anthropic-ai/claude-code
```

2. Navigate to the project directory:

```bash
cd /path/to/SS-OCT-SW
```

3. Connect local remote control:

```bash
claude remote-control
```

This connects your local terminal to the Claude Code web/desktop app, enabling file access and terminal execution from the browser.
